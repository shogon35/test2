# オーバーウォッチ「レンダリングデバイスが見つかりません」エラー調査

## エラー概要

「レンダリングデバイスが見つかりません。ゲームを終了します。」（英語: "Your rendering device has been lost! Application closing!"）は、GPU がゲームのレンダリング処理を続行できなくなった際に発生するエラーです。GPU がクラッシュまたはリセットされ、OS の TDR（Timeout Detection and Recovery）機能が作動した場合に表示されます。

---

## 主な原因

### 1. GPU ドライバーの問題
- ドライバーが古い、または破損している
- 最新ドライバーに不具合がある（特にリリース直後）
- ドライバーのインストールが不完全

### 2. GPU のオーバークロック
- GPU コアクロックやメモリクロックの手動オーバークロック
- MSI Afterburner、EVGA Precision 等のツールによる設定
- 工場出荷時オーバークロック済みモデルでも発生する場合あり

### 3. GPU の過熱（オーバーヒート）
- GPU 温度が限界値を超えている（通常 90°C 以上で危険）
- ケース内のエアフローが不十分
- GPU ファンの故障や埃の蓄積
- サーマルペーストの劣化

### 4. バックグラウンドアプリケーションの干渉
- GPU リソースを消費する他のアプリケーション
- オーバーレイソフト（Discord オーバーレイ、GeForce Experience 等）
- ハードウェアアクセラレーションを使用するブラウザ（Chrome 等）
- 録画・配信ソフト（OBS、ShadowPlay 等）

### 5. 電力供給の問題
- PSU（電源ユニット）の容量不足
- GPU への補助電源ケーブルの接続不良
- 電源ケーブルの劣化

### 6. Windows の設定・問題
- Windows の TDR 設定
- Windows Update による互換性の問題
- 仮想メモリ（ページファイル）の設定不備

### 7. ハードウェアの物理的な問題
- GPU が PCIe スロットにしっかり装着されていない
- GPU 自体の故障（VRAM エラー等）
- マザーボードの PCIe スロットの不具合

---

## 解決策

### 対策 1: GPU ドライバーの再インストール（最優先）

1. DDU（Display Driver Uninstaller）をダウンロード
2. PC をセーフモードで起動
3. DDU を使用して現在のドライバーを完全にアンインストール
4. PC を再起動
5. GPU メーカーの公式サイトから最新の安定版ドライバーをインストール
   - NVIDIA: nvidia.com/drivers
   - AMD: amd.com/support
6. 最新ドライバーで問題が続く場合は、1〜2 世代前の安定版を試す

### 対策 2: オーバークロックの無効化

1. MSI Afterburner 等のオーバークロックツールを開く
2. すべての設定をデフォルトに戻す
3. 可能であれば GPU クロックをデフォルトより若干下げる（アンダークロック）
4. 工場出荷時 OC モデルの場合、メーカーツールで「サイレントモード」に切り替え

### 対策 3: バックグラウンドアプリの終了

1. 不要なバックグラウンドアプリケーションを終了
2. 各種オーバーレイを無効化:
   - Discord: ユーザー設定 → ゲームオーバーレイ → オフ
   - GeForce Experience: 設定 → ゲーム内オーバーレイ → オフ
3. ブラウザのハードウェアアクセラレーションを無効にする
4. ゲームプレイ中はブラウザ（特に動画再生）を閉じる

### 対策 4: GPU 温度の確認と対策

1. GPU-Z や HWMonitor で GPU 温度を監視
2. ゲームプレイ中 85°C 以上なら対策が必要
3. GPU のファンやヒートシンクの埃を除去（エアダスター使用）
4. ケースファンの追加やエアフロー改善を検討
5. Overwatch 内でフレームレート上限をモニターのリフレッシュレートに設定
6. レンダリングスケール・グラフィック品質を下げる

### 対策 5: Battle.net のスキャンと修復

1. Battle.net アプリ → Overwatch → オプション（歯車アイコン）
2. 「スキャンと修復」を実行してゲームファイルの破損を修復

### 対策 6: 電力供給の確認

1. GPU の補助電源ケーブルがしっかり接続されていることを確認
2. 分岐ケーブル（デイジーチェーン）ではなく個別ケーブルを使用
3. PSU の容量が GPU の推奨電力を満たしているか確認

### 対策 7: Windows 設定の調整

**TDR の調整（上級者向け）:**
- レジストリエディタで `HKEY_LOCAL_MACHINE\SYSTEM\CurrentControlSet\Control\GraphicsDrivers` を開く
- `TdrDelay` という DWORD 値を作成し、値を `10`（秒）に設定
- PC を再起動

**その他:**
- Windows Update を最新の状態にする
- コマンドプロンプト（管理者）で `sfc /scannow` を実行
- 電源プランを「高パフォーマンス」に変更

### 対策 8: ハードウェアの確認

1. PC の電源を切り、GPU を取り外して再装着
2. PCIe スロットの接点を確認し埃があれば清掃
3. 別の PCIe スロットが利用可能なら試す
4. 可能であれば別の PC で GPU をテスト

---

## トラブルシューティング推奨順序

| 優先度 | 対策 | 難易度 |
|--------|------|--------|
| 1 | GPU ドライバーの更新（DDU 使用） | 低 |
| 2 | オーバークロックの無効化 | 低 |
| 3 | バックグラウンドアプリの終了 | 低 |
| 4 | GPU 温度の確認と対策 | 低〜中 |
| 5 | ゲーム内グラフィック設定の変更 | 低 |
| 6 | Battle.net のスキャンと修復 | 低 |
| 7 | 電源ケーブルの確認 | 中 |
| 8 | GPU の再装着 | 中 |
| 9 | TDR レジストリの調整 | 高 |
| 10 | ハードウェアの交換・修理 | 高 |

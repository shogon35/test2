# GPU ドライバー クリーンインストール手順書

オーバーウォッチ「レンダリングデバイスが見つかりません」エラー対策として、
DDU を使った GPU ドライバーの完全な再インストール手順を説明します。

---

## 事前準備（通常の Windows で行う）

### ステップ 1: 現在の GPU を確認する

1. キーボードで `Windows キー + X` を押す
2. 「デバイスマネージャー」をクリック
3. 「ディスプレイアダプター」を展開する
4. 表示されている GPU の名前をメモする
   - 例: `NVIDIA GeForce RTX 4070` や `AMD Radeon RX 7800 XT`

### ステップ 2: 新しいドライバーを先にダウンロードする

> **重要**: セーフモードではネットに繋がらない場合があるため、先にダウンロードしておく

**NVIDIA の場合:**
1. ブラウザで「NVIDIA ドライバー ダウンロード」と検索
2. nvidia.co.jp のドライバーダウンロードページを開く
3. 自分の GPU に合った項目を選ぶ
   - 製品の種類: GeForce
   - 製品シリーズ: 例）GeForce RTX 40 Series
   - 製品: 例）GeForce RTX 4070
   - OS: Windows 11 64bit（または Windows 10 64bit）
   - ダウンロードタイプ: Game Ready ドライバー
4. 「検索」→「ダウンロード」をクリック
5. デスクトップなど、わかりやすい場所に保存する

**AMD の場合:**
1. ブラウザで「AMD ドライバー ダウンロード」と検索
2. amd.com のサポートページを開く
3. 「グラフィックス」→ 自分の GPU シリーズを選ぶ
4. 「送信」→ OS を選ぶ → ドライバーをダウンロード
5. デスクトップなど、わかりやすい場所に保存する

### ステップ 3: DDU をダウンロードする

1. ブラウザで「DDU Display Driver Uninstaller」と検索
2. 公式サイト（wagnardsoft.com）からダウンロード
3. ZIP ファイルをデスクトップに展開（解凍）する

---

## セーフモードで起動する

### ステップ 4: セーフモードに入る

**方法 A（設定アプリから）:**
1. `Windows キー + I` で設定を開く
2. 「システム」→「回復」を選ぶ（Windows 10 は「更新とセキュリティ」→「回復」）
3. 「PC の起動をカスタマイズする」の「今すぐ再起動」をクリック
4. 青い画面が表示される:
   - 「トラブルシューティング」をクリック
   - 「詳細オプション」をクリック
   - 「スタートアップ設定」をクリック
   - 「再起動」をクリック
5. 数字キーの `4` または `F4` を押して「セーフモードを有効にする」を選ぶ

**方法 B（Shift + 再起動）:**
1. スタートメニューの電源ボタンをクリック
2. `Shift キー` を押しながら「再起動」をクリック
3. 以降は方法 A の手順 4 と同じ

> **メモ**: セーフモードでは画面の解像度が低くなり、壁紙が黒くなりますが正常です

---

## DDU でドライバーを完全削除する

### ステップ 5: DDU を実行する

1. デスクトップに展開した DDU フォルダを開く
2. 「Display Driver Uninstaller.exe」をダブルクリックして起動
3. 警告が出た場合は「はい」で進む

### ステップ 6: DDU の設定を確認する

1. DDU が起動したら、右側の設定を確認:
   - 「デバイスの種類を選択」→ **GPU** を選ぶ
   - 「デバイスを選択」→ **NVIDIA** または **AMD** を選ぶ
2. 左側にオプションが並んでいるが、**デフォルトのままでOK**

### ステップ 7: ドライバーを削除する

1. 左上の3つのボタンから **「クリーン＆再起動」** をクリック
   ```
   ┌─────────────────────────────┐
   │ ● クリーン＆再起動     ← これ！│
   │ ○ クリーン＆シャットダウン     │
   │ ○ クリーン（再起動なし）       │
   └─────────────────────────────┘
   ```
2. DDU がドライバーの削除を始める（1〜3 分程度）
3. 完了すると自動的に PC が再起動する

> **注意**: 再起動後は画面の解像度が低く表示されますが、これはドライバーが削除されたためで正常です

---

## 新しいドライバーをインストールする

### ステップ 8: ドライバーをインストールする

**NVIDIA の場合:**
1. ステップ 2 でダウンロードしたインストーラー（.exe）をダブルクリック
2. 「NVIDIA グラフィックスドライバー」を選択（GeForce Experience は任意）
3. インストールの種類で **「カスタム」** を選ぶ
4. **「クリーンインストールの実行」にチェック** を入れる ← 重要！
5. 「次へ」をクリックしてインストール開始
6. 完了したら PC を再起動

**AMD の場合:**
1. ステップ 2 でダウンロードしたインストーラー（.exe）をダブルクリック
2. インストールが始まったら **「工場出荷時リセット」** にチェック ← 重要！
3. 「インストール」をクリック
4. 完了したら PC を再起動

### ステップ 9: インストールの確認

1. PC 再起動後、画面の解像度が元に戻っていれば成功
2. 確認方法:
   - デスクトップ右クリック →「NVIDIA コントロールパネル」または「AMD Software」が表示されればOK
   - または `Windows キー + X` →「デバイスマネージャー」→「ディスプレイアダプター」に GPU 名が表示されていればOK

---

## ドライバー更新後の確認

### ステップ 10: オーバーウォッチで動作確認

1. PC を再起動してからオーバーウォッチを起動
2. まずは「練習場」やトレーニングモードで 10〜15 分程度プレイ
3. エラーが出なければ通常のマッチに進む

### うまくいかない場合

- **最新ドライバーでもエラーが出る場合**:
  → DDU で再度削除し、1〜2 世代前のドライバーを試す
  （NVIDIA の場合、ダウンロードページの「ベータドライバ & 過去のドライバ」から入手可能）

- **ドライバーインストール自体が失敗する場合**:
  → GPU のハードウェア故障の可能性あり（docs/overwatch-rendering-device-lost.md の対策 8 を参照）

## よくある質問

**Q: DDU は毎回使う必要がある？**
A: いいえ。通常のドライバー更新では不要です。今回のようにエラーが発生した場合や、ドライバーの不具合が疑われる場合にのみ使います。

**Q: セーフモードに入らずに DDU を使ってもいい？**
A: 動作はしますが、一部のドライバーファイルが使用中で削除できない場合があります。確実に削除するためセーフモードでの実行を推奨します。

**Q: DDU で他のデータが消えることはある？**
A: いいえ。DDU が削除するのは GPU ドライバー関連のファイルのみです。写真やゲームのセーブデータ等には影響しません。
